# DRIFT · 轻钓世界

一款移动端优先、免注册的纯前端钓鱼网页游戏。无需框架、API 或数据库。

## 在线部署

本仓库通过 GitHub Actions 自动部署到 GitHub Pages。向 `main` 分支推送提交后会自动发布；也可以在 Actions 页面手动运行部署工作流。

## 玩法

1. 选择国家和钓场。
2. 抛竿，等待咬钩提示并及时提竿。
3. 搏鱼时按住主按钮收线，松开按钮降低拉力，避免鱼线断裂。
4. 收集鱼类、赚取金币、解锁鱼饵并升级鱼线。

## 内容

- 10 个国家、80 种地区代表鱼类。
- 4 档稀有度、黄金咬口、连胜奖励。
- 鱼类图鉴、长度与重量记录、金币和装备升级。
- Canvas 动态钓场、鱼影和搏鱼张力反馈。
- 手机触控、震动提示、声音开关。
- PWA 清单和 Service Worker，支持添加到主屏幕及离线缓存。

## 技术

纯 HTML、CSS、JavaScript；无第三方运行时依赖。游戏进度保存在当前浏览器的 `localStorage`，不同设备之间不会自动同步。
